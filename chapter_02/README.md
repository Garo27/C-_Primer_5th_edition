>[Задание 2.1]

short , int , long , long long имеют разные размеры:  
```
short: не менее 16 бит.
int: по меньшей мере такого же размера, как short.  
long: не менее 32 бит и не меньше размера int.  
long long: не менее 64 бит и не меньше размера long, введенного новым стандартом.
```

Разница между знаковыми и беззнаковыми типами:
```
signed: хранят как положительные, так и отрицательные значения.
unsigned: хранят только неотрицательные значения (от 0 и выше).
```

разница между типами float и double:
```
float: число с плавающей запятой одинарной точности, содержащее не менее 6 значащих цифр.
double: число с плавающей запятой двойной точности, обеспечивающее не менее 10 значащих цифр.
```

Следует использовать типы данных с плавающей запятой. Double обеспечивает более высокую точность, чем float.

## Вложенные области видимости
``` c++
#include <iostream>
// Программа предназначена исключительно для демонстрации.
// Использование в функции глобальной переменной, а также определение
// одноименной локальной переменной - это очень плохой стиль
// программирования
int reused = 42; // reused имеет глобальную область видимости
int main()
{
    int unique = 0; // unique имеет область видимости блока
    // вывод #1: используется глобальная reused; выводит 42 0
    std::cout << reused << " " << unique << std::endl;
    int reused = 0; // новый локальный объект по имени reused скрывает
                    // глобальный reused
    // вывод #2: используется локальная reused; выводит 0 0
    std::cout << reused << " " << unique << std::endl;
    // вывод #3: явное обращение к глобальной reused; выводит 42 0
    std::cout << ::reused << " " << unique << std::endl;
    return 0;
}
```
